# Panashe Chandiwana — Portfolio

Personal portfolio for Panashe M. Chandiwana, a Computer Engineering graduate, AI engineer, and software developer. Built with Next.js (App Router), TypeScript, Tailwind CSS, and Framer Motion.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it locally.

## Structure

- `app/` — routes (`/`, `/about`, `/skills`, `/projects`, `/projects/[slug]`, `/contact`)
- `components/` — layout (`Navigation`, `Footer`) and page sections (`components/sections/`)
- `data/projects.ts` — project content source of truth
